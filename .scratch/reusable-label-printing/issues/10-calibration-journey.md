# Prototype the calibration journey

Type: prototype
Status: open
Blocked by: 03, 05, 06, 09

## Question

What printable artifact and polished standalone-application interaction let a human identify a printing setup, apply the required dialog settings, measure output, enter observations, verify the resulting printer profile, and recognize when recalibration is required with the fewest confusing or wasteful steps?

## Comments

- The web application must restore past hardware and environment details, sheet-layout product data, calibration state, printer profiles, label content, and physical-output preferences.
- Label content needs a real-time label preview and a sheet-level preview. Preview remains a software rendering aid, not physical evidence.
- Users need an optional content inset in addition to the safe area established by alignment tolerance.
