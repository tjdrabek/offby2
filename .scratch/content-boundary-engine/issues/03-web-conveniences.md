# 03 — The web conveniences ship

**What to build:** A web developer styles a preview and verifies it without writing conversion code: a new `offby2/web` entry point offers the CSS custom-property map for a boundary and an element-readback shim for the pixel agreement check. The quarter-turn padding reassignment and the agreement judgement are core functions over plain data; the adapters contain zero arithmetic, and the shim only gathers numbers from an element.
